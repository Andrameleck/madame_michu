Politique de confidentialite de Madame Michu

Derniere mise a jour : 25 aout 2026.

Donnees traitees localement

L'extension lit les messages, dossiers, identites et calendriers Thunderbird afin de produire des rapports, rechercher des informations et creer les rendez-vous demandes. L'index des mails, les reglages, les cles API et les jetons OAuth sont conserves dans le profil Thunderbird local. Les secrets ne sont pas journalises, mais ce stockage n'est pas un coffre-fort chiffre.

Transmission a un provider LLM

Avec le consentement explicite, un provider distant peut recevoir les questions, prompts, sujets, expediteurs, dates, extraits de mails et textes necessaires aux embeddings. L'extension ne peut pas verifier ses pratiques de collecte, de journalisation, de conservation ou de reutilisation. Un LLM local est preferable ; n'utilise un service distant que si ses garanties sont connues.

Consentement et controle

Aucun appel distant n'est autorise avant l'acceptation explicite dans les options. Le consentement peut etre retire a tout moment. Les providers distants doivent utiliser HTTPS. HTTP est accepte uniquement pour localhost.

Meteo de Montpellier

L'encart meteo est actif par defaut. Le nom de Montpellier est envoye a Open-Meteo pour obtenir ses coordonnees puis les previsions. Aucun mail, rapport, calendrier, historique de conversation ou identifiant Thunderbird n'est transmis. La reponse est mise en cache localement pendant trente minutes.

Flash d'actualite

Madame Michu consulte toutes les cinq minutes le flux RSS ou Atom choisi dans les options (The Conversation France par defaut). Aucun mail, calendrier, rapport, historique ou terme de recherche n'est envoye. Les themes choisis filtrent localement les titres recus, qui ne sont pas reecrits par le LLM.

Partage, telemetrie et conservation

Madame Michu n'exploite aucun serveur propre, ne vend aucune donnee et n'integre aucune telemetrie. La conservation par un provider LLM depend du service choisi et de son contrat ; l'utilisateur doit consulter sa politique avant de l'activer. Supprimer l'extension efface normalement son stockage avec le profil Thunderbird, sous reserve des sauvegardes locales.
